# מגירת המילים 📇

אפליקציית תרגול אוצר מילים באנגלית — כרטיסיות, בחירה מרובה והקלדה, עם רמות קושי, שעון לתשובה, ואפשרות לכתוב פירושים אישיים.

## איך מקבלים קישור קבוע לאפליקציה (GitHub Pages)

1. נכנסים לריפו הזה באתר GitHub, ולוחצים על **Settings**.
2. בתפריט הצד לוחצים על **Pages**.
3. תחת "Build and deployment" → "Branch", בוחרים את הענף `main` (או את הענף הנוכחי אחרי שממזגים אליו) ותיקיה `/ (root)`, ואז **Save**.
4. אחרי דקה-שתיים יופיע למעלה קישור בסגנון:
   `https://<שם-המשתמש>.github.io/<שם-הריפו>/`
5. פותחים את הקישור הזה בטלפון ומוסיפים אותו למסך הבית (כמו שהוסבר בצ'אט) — עכשיו זה קישור קבוע משלכם, לא תלוי ב-Claude.

## מה יש בתיקייה

- `index.html` — כל האפליקציה (עמוד אחד)
- `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png` — קבצים שמאפשרים להתקין את האפליקציה כמו אפליקציה אמיתית על הטלפון
