# דיל סיטי · Deal City

**לשחק עכשיו:** https://alongdev26-glitch.github.io/-1/

משחק מסחר בנכסים בעברית לדפדפן ולטלפון, עם לוח מקורי של ערים מכל הארץ: ירושלים, תל-אביב, חיפה, רמת-גן ועוד.
משחקים נגד 1 עד 3 בוטים, עם 2 עד 4 אנשים על אותו טלפון, או אונליין עם קוד חדר ("צור קוד" / "רשום קוד"). אפשר לשלב בוטים בכל מצב.

משחק אונליין ("צור קוד" / "רשום קוד"): באתר ובאפליקציה הטלפונים מתחברים ישירות זה לזה (WebRTC דרך PeerJS), בלי חשבון ובלי שרת משלנו. מי שיצר את הקוד מחזיק את החדר, וצריך להשאיר את המשחק פתוח. בקישור של claude.ai החדר נשמר ב-`db` של ה-Artifact.

## איך מריצים

```bash
npm install
npm run dev      # פותח את המשחק בכתובת http://localhost:5173
```

בטלפון: פתח את הכתובת שמופיעה אחרי ‎`--host` (למשל ‎`npm run dev -- --host`). המשחק בנוי לטלפון לאורך, ועובד גם לרוחב ובמחשב.

## פקודות

| פקודה | מה היא עושה |
| --- | --- |
| `npm run dev` | שרת פיתוח |
| `npm run build` | בדיקת טיפוסים ובנייה לתיקיית `dist/` |
| `npm test` | בדיקות של חוקי המשחק (Vitest) |

## איך לפרסם

התיקייה `dist/` שנוצרת אחרי `npm run build` היא אתר סטטי. אפשר להעלות אותה כמו שהיא ל-GitHub Pages, ל-Netlify או ל-Vercel.

במאגר יש workflow ‏(`.github/workflows/pages.yml`) שבונה ומפרסם את המשחק ל-GitHub Pages בכל דחיפה ל-`main`. צריך להפעיל פעם אחת: Settings ← Pages ← Source: GitHub Actions.

## מבנה הקוד

- `src/data/board.ts`: 40 המשבצות של הלוח (שמות, מחירים ושכירות)
- `src/data/cards.ts`: כרטיסי "הפתעה" ו"תיבת המזל"
- `src/engine/`: חוקי המשחק כפונקציות טהורות, וה-AI של שחקני המחשב
- `src/ui/`: הלוח, הקוביות והחלונות
- `src/tabs/`: ארבעת עמודי המשחק (לוח, הנכסים שלי, נכסים פנויים, פרופיל)
- `src/screens/`: מסך פתיחה, הגדרת שחקנים ובחירת כלי, מסגרת המשחק עם סרגל העמודים, ומסך הניצחון
- `store/`: חומרי חנות האפליקציות, ו-`store/brand-src/` מקורות הלוגו והאייקונים
- `ASSETS.md`: מאיפה כל תמונה, צליל ופונט

## חוקים

- כל שחקן מתחיל עם ש"ח 2000, ומקבל ש"ח 200 בכל מעבר ב"התחלה", וש"ח 400 כשנוחתים עליה בדיוק.
- דאבל נותן תור נוסף. שלושה דאבלים ברצף שולחים לכלא.
- נכס שלא קונים יוצא למכירה פומבית. מי שהוציא אותו למכירה לא יכול להציע עליו.
- מי שיש לו את כל הרחובות באותו צבע גובה שכירות כפולה, ורק הוא יכול לבנות בתים ומלון. הבנייה חייבת להיות שווה בין כל הרחובות בצבע.
- משכנתא (אפשר לכבות אותה בתחילת המשחק): מהקנייה הראשונה במשחק, כל 7 סבבים כל שחקן משלם לקופת הלוטו חצי ממחיר כל נכס שלו. אין משכון של נכסים בודדים: מי שחסר לו כסף מוכר בתים, או מוכר נכס לבנק בחצי ממחירו.
- מהכלא יוצאים בתשלום ש"ח 60, בדאבל או עם כרטיס יציאה.
- השחקן האחרון שנשאר בלי לפשוט רגל מנצח.
- קופת הלוטו: מסים, קנסות וכרטיסי תשלום נכנסים לקופה, ומי שנוחת על "חניה חינם" לוקח את כולה.
- העברות: בתור שלך אפשר להציע לשחקן אחר עסקה (נכסים בלי בתים, כסף, כרטיסי יציאה מהכלא). הוא יכול לאשר, לסרב או להציע הצעה נגדית (עד 3 סבבים). גם הבוטים מציעים עסקאות.
